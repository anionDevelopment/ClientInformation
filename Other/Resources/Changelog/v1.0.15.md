# Release notes

## Changes

- Added geo-information as library.
- The scripts of the codeunits now use the current api of ScriptCollection (the api "TasksForCommonProjectStructure" which they used does not exist anymore, so they were not runnable)
- The codeunit-files now implement the codeunit-specification-version 3.0.4
- Updated the versions of the used images
- Removed the configuration of GitVersion, which is not used anymore
- Updated GRYLibrary to its newest version
- The application starts again: the metrics-service asked for a log-type which is not registered in the dependency-injection-container, which let the application fail at startup
- Corrected the version of ExtendedXmlSerializer: the used version of GRYLibrary needs a newer one at runtime than the one which was referenced, so the application failed with "Could not load file or assembly"
- The health-check works again: it asked for a log-type which is not registered in the dependency-injection-container, so every request to the health-check-endpoint failed with statuscode 500 and the container never became healthy
- The healthcheck of the container now uses an interval of 30 seconds, a timeout of 20 seconds and a start-period of 2 minutes
- The container now passes the environment-variable "EnforceVerbose" on to the application
- Declared ClientInformationLibrary as dependency of ClientInformationBackend, which uses it
- Adapted the build-scripts and the project-files to the current version of ScriptCollection
- Updated Swashbuckle.AspNetCore to 10.3.1
- Fixed the remote-address of the repository and the links to it (it is located in the organization anionDevelopment)
